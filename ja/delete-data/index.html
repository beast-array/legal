Beast Array(獣陣)— データの削除方法

最終更新日: 2026年10月26日
開発者: Martin Ho
連絡先: beastarray@mail.grokbot.com

Beast Array にはアカウントも独自のサーバーもありません。進行状況、設定、年齢確認の結果は、お使いのデバイスにのみ保存されます。

  1. ゲームのデータを削除する。 iPhone からアプリを削除します: 「設定」→「一般」→「iPhone ストレージ」→「Beast Array」→「App を削除」(「Appを取り除く」ではありません)。ゲームがデバイスに保存したデータが削除されます。元に戻すことはできず、復元用のクラウドセーブもありません。
  2. 広告 ID。 iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」で、広告 ID のリセットや制限、アプリからのトラッキング要求の停止ができます。Google が保有する広告データは、Google 自身の設定で管理します。
  3. 購入。 購入記録は当方ではなく Apple が保管しています。App Store の購入履歴で確認できます。当方で削除することはできません。
  4. データについてのお問い合わせ。 beastarray@mail.grokbot.com にメールしてください。当方が保有しうる個人データは、お送りいただいたメールのみです。法律上保管が必要な場合を除き、ご要望に応じて削除します。
