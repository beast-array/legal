ひとことで言うと

  • このゲームはオフラインで遊べます。アカウントも登録も必要ありません。
  • 進行状況と設定はお使いのデバイスにのみ保存されます。当方は独自のサーバーを持たず、ゲームデータを受け取りません。
  • このゲームは Google AdMob(Google Mobile Ads SDK)で広告を表示します。Google は、広告の表示と効果測定のために、デバイスの広告 ID や一部のデバイス情報を収集することがあります。
  • 購入は Apple が処理します。当方が支払い情報を受け取ることはありません。
  • このゲームには、分析 SDK もクラッシュレポート SDK もなく、クラウドセーブもありません。
  • ご利用には 13 歳以上であることが必要です。

デバイスに保存されるデータ

ゲームは、進行状況、設定、年齢確認の結果(単なるフラグ)をお使いのデバイスに保存します。これらのデータが当方に送信されることはありません。ゲームを削除すると、一緒に削除されます。

広告

無料の本ゲームでは Google AdMob の広告が表示されます。広告の読み込み時に、Google Mobile Ads SDK は、広告 ID、IP アドレス、デバイスとアプリの情報、広告の表示とクリックに関するデータを、広告の配信、効果測定、不正防止のために収集・利用することがあります。当方はこれらのデータを受け取りません。

パーソナライズ広告は、同意した場合にのみ表示されます。まず同意フォーム(Google UMP、EEA や英国などで表示)、次に iOS の「トラッキングを許可」(ATT)の確認です。拒否した場合、または 13〜15 歳の場合は、パーソナライズされない広告のみが表示されます。

選択はいつでも iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」で変更でき、広告 ID のリセットや制限もできます。Google のデータの扱いについては Google のプライバシーポリシー(https://policies.google.com/privacy)をご覧ください。

一度だけの「広告を削除」(Remove Ads)購入で、対戦の合間の広告が表示されなくなります。ヒントチケットを得るために自分で選んで見るリワード広告は引き続き利用できるため、広告 SDK は動作することがあります。

購入

購入は App Store を通じて行われ、Apple が自社の規約とプライバシーポリシーに従って処理します。当方があなたの氏名、カード情報、支払い情報を受け取ることはありません。ゲームは「広告を削除」が購入済みかどうかだけを把握します。

当方が行わないこと

当方にはアカウントの仕組みも独自のサーバーもありません。分析 SDK やクラッシュレポート SDK は使用せず、クラウドセーブも提供せず、個人データの販売も行いません。

子ども

このゲームは 13 歳以上の方向けです。初めて起動すると、生まれた年月を尋ねます。この回答が当方に送信されることはありません。13 歳未満の場合は先へ進めず、利用することもできません。13 歳未満の子どもの個人データを故意に収集することはありません。13 歳未満の子どもが情報を送ってきたと思われる場合は、メールでお知らせください。削除します。

あなたの権利

お住まいの地域(例: EEA、英国、カリフォルニア州)によっては、個人データへのアクセス、訂正、削除を求める権利や、利用に異議を唱える権利があります。当方が保有するあなたの情報はほとんどありません。ゲームのデータはデバイス上にあり、当方が保有しうる個人データは、お送りいただいたメールのみです。権利を行使するには、メールでご連絡ください。Google や Apple が保有するデータは各社が扱いますので、各社にご連絡いただくか、iPhone の設定をご利用ください。

国際的なデータ移転

当方にはサーバーがありません。広告データは Google が処理し、Google 自身の保護措置のもとで、お住まいの国以外で処理されることがあります。購入は Apple が処理します。

変更
