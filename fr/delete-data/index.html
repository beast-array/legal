Beast Array (獸陣) — Comment supprimer vos données

Dernière mise à jour : 26 octobre 2026
Développeur : Martin Ho
Contact : beastarray@mail.grokbot.com

Beast Array n'a ni compte ni serveur propre. Votre progression, vos réglages et le résultat de la vérification de l'âge sont stockés uniquement sur votre appareil.

  1. Supprimer les données du jeu. Supprimez l'app de votre iPhone : Réglages → Général → Stockage iPhone → Beast Array → Supprimer l'app (et non « Décharger l'app »). Cela supprime ce que le jeu a enregistré sur votre appareil. C'est irréversible et il n'y a pas de sauvegarde dans le cloud pour restaurer.
  2. Identifiant publicitaire. Vous pouvez réinitialiser ou limiter l'identifiant publicitaire et empêcher les apps de demander à vous suivre dans Réglages de l'iPhone → Confidentialité et sécurité → Suivi. Les données publicitaires détenues par Google se gèrent dans les réglages de Google.
  3. Achats. L'historique de vos achats est conservé par Apple, pas par nous. Vous pouvez le consulter dans votre historique d'achats de l'App Store ; nous ne pouvons pas le supprimer.
  4. Questions sur vos données. Écrivez à beastarray@mail.grokbot.com. Les seules données personnelles que nous pouvons détenir sont les e-mails que vous nous envoyez. Nous les supprimerons à votre demande, sauf si la loi nous oblige à les conserver.
