Beast Array — Assistance

Besoin d’aide avec Beast Array ? Écrivez-nous, nous lirons votre message.

Contact: beastarray@mail.grokbot.com

Réponses rapides

Comment supprimer les publicités ?

Achetez dans le jeu l’achat unique « Remove Ads » (supprimer les publicités). Il supprime les publicités affichées entre les parties. Les publicités avec récompense facultatives, que vous regardez uniquement si vous le souhaitez pour obtenir des tickets d’indice, restent disponibles. Les achats sont gérés par Apple.

Comment restaurer mon achat ?

Si vous avez réinstallé le jeu ou changé d’iPhone, utilisez « Restore Purchases » (restaurer les achats) dans le jeu (boutique ou réglages), connecté avec le même identifiant Apple que celui de l’achat.

Comment supprimer mes données ?

Le jeu ne conserve ses données que sur votre appareil. Supprimez l’app pour les effacer. Voir comment supprimer vos données.

Puis-je transférer ma progression sur un nouvel iPhone ?

Il n’y a ni compte ni sauvegarde dans le cloud ; nous ne pouvons donc pas restaurer ni transférer votre progression.

À partir de quel âge puis-je jouer ?

Vous devez avoir 13 ans ou plus pour utiliser le jeu.
