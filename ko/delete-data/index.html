Beast Array(獸陣) — 내 데이터 삭제 방법

최종 업데이트: 2026년 10월 26일
개발자: Martin Ho
문의: beastarray@mail.grokbot.com

Beast Array에는 계정도 자체 서버도 없습니다. 진행 상황, 설정, 연령 확인 결과는 기기에만 저장됩니다.

  1. 게임 데이터 삭제. iPhone에서 앱을 삭제하세요: 설정 → 일반 → iPhone 저장 공간 → Beast Array → 앱 삭제(앱 오프로드가 아님). 게임이 기기에 저장한 데이터가 삭제됩니다. 되돌릴 수 없으며, 복원할 클라우드 저장도 없습니다.
  2. 광고 ID. iPhone 설정 → 개인정보 보호 및 보안 → 추적에서 광고 ID를 재설정하거나 제한하고, 앱의 추적 요청을 막을 수 있습니다. Google이 보유한 광고 데이터는 Google 자체 설정에서 관리합니다.
  3. 구매. 구매 기록은 저희가 아니라 Apple이 보관합니다. App Store 구매 내역에서 확인할 수 있으며, 저희는 삭제할 수 없습니다.
  4. 데이터 관련 문의. beastarray@mail.grokbot.com로 이메일을 보내 주세요. 저희가 보유할 수 있는 개인 데이터는 보내 주신 이메일뿐입니다. 법적으로 보관해야 하는 경우를 제외하고 요청 시 삭제합니다.
