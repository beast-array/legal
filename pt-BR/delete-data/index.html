Beast Array (獸陣) — Como remover seus dados

Última atualização: 26 de outubro de 2026
Desenvolvedor: Martin Ho
Contato: beastarray@mail.grokbot.com

O Beast Array não tem conta nem servidor próprio. Seu progresso, suas configurações e o resultado da verificação de idade ficam guardados apenas no seu dispositivo.

  1. Excluir os dados do jogo. Exclua o app do seu iPhone: Ajustes → Geral → Armazenamento do iPhone → Beast Array → Apagar App (não "Descarregar App"). Isso remove o que o jogo guardou no seu dispositivo. Não dá para desfazer e não há salvamento na nuvem para restaurar.
  2. ID de publicidade. Você pode redefinir ou limitar o ID de publicidade e impedir que apps peçam para rastreá-lo em Ajustes do iPhone → Privacidade e Segurança → Rastreamento. Os dados de publicidade que o Google tem são gerenciados nas configurações do Google.
  3. Compras. O registro das suas compras é mantido pela Apple, não por nós. Você pode vê-lo no histórico de compras da App Store; não podemos excluí-lo.
  4. Dúvidas sobre seus dados. Escreva para beastarray@mail.grokbot.com. Os únicos dados pessoais que podemos ter são os e-mails que você nos enviar. Vamos excluí-los se você pedir, a menos que a lei nos obrigue a guardá-los.
