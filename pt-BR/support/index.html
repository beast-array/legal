Respostas rápidas

Como removo os anúncios?

Compre no jogo a compra única “Remove Ads” (remover anúncios). Ela remove os anúncios exibidos entre as partidas. Os anúncios premiados opcionais, que você só assiste se quiser, para ganhar tíquetes de dica, continuam disponíveis. As compras são processadas pela Apple.

Como restauro minha compra?

Se você reinstalou o jogo ou trocou de iPhone, use “Restore Purchases” (restaurar compras) no jogo, em “Settings → Purchases”, com o mesmo ID Apple usado na compra.

Como apago meus dados?

O jogo guarda os dados apenas no seu dispositivo. Exclua o app para removê-los. Veja como remover seus dados.

Posso levar meu progresso para um iPhone novo?

Não há conta nem save na nuvem, então não conseguimos restaurar nem transferir seu progresso.

Qual é a idade para jogar?

Você precisa ter 13 anos ou mais para usar o jogo.
